# Independent XAUUSD recorder

User authorized continuous data collection, persistence and history recovery. Keep execution process/config/positions/runtime DLL unchanged. Existing C# transport, tick pagination and conservative Bid/Ask merger reused. Separate read-only connection rejects all order/config mutation requests. Pin selected demo account identity at first startup; reject identity change.

Store raw timestamped side updates in daily append CSV journals (broker and receive times, source session), preserving duplicates/late events as evidence. Ignore untimestamped/invalid/foreign-symbol events with counters. Never forward-fill absent sides into raw journal. Flush disk on active quote reception each1s and between API operations, plus on errors/shutdown/day rotation. A hung request may delay an idle flush until the30s transport timeout; hourly recovery repairs this provisional tail. Incomplete last line after crash removed at reopen; journal is evidence, not certified complete history.

Backfill full UTC hours, end-exclusive, only after60s settlement lag;4requests/sec transport limit, capped pagination from TickHistory. Start yesterdayUTC by default (explicit --from supports older days); persisted coverage resumes across process/network outages. Store atomic hourly gzip raw tick files with existing CSV schema, then checkpoint. No merging live+history: authoritative history replaces missing/overlapping live coverage without duplicate rows in research cache. Preserve real duplicate-ms ticks. Empty response means broker queried-empty, not proof market closed or no gaps. Entire current hour remains pending until settled.

After24covered hours, stream hourly files to an atomic daily data/fxpro-v2/XAUUSD-DATE.csv.gz compatible with existing backtests. Never overwrite existing daily data; write no partial day to canonical path. Coverage checkpoint advances only after durable gzip and successful publication at day boundary. Rewind if referenced hourly file absent; corrupt checkpoint fails closed, log error. Retry connections with bounded exponential backoff, heartbeat requests every2s to drain socket; token expiry requires existing OAuth reconnection, no independent token refresh race. Status JSON includes heartbeat, counters, covered interval, pending hours, lastquote and sanitized error type; no keys/login/pairing data. Daily-files are queried coverage, not an independent audit of broker completeness.

Deploy dedicated user systemd/Podman service with isolated built DLL under ignored audit/recorder-runtime; no worker/dashboard restart. Graceful SIGTERM flushes journal. Tests fake broker only: write/rotate/reopen/truncate partial tail, side-preservation/invalid filtering, allowlist rejects orders, history failure does not advance cursor, atomic overwrite/idempotent retry, tied rows preserved, missing-hour rewind, day publishing only when complete, closed-hour settlement. Real smoke test read-only startup/history/stream status; weekend stream may only send cached snapshot and must not be called fresh ticks. Document automatic startup and any privilege/expiry limitations.
